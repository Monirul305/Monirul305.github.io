Designed and manufactured two iterations of a large-volume industrial 3D printer
used in-house for rapid prototyping of robot components across all Cybernetics
platforms. V2 adds direct-drive dual-gear extruder, BigTreeTech / TMC2209
controller board, 4.3″ touchscreen, and WiFi/Ethernet connectivity.

### Specifications (v2)

| Parameter | Value |
|---|---|
| Build volume | 510 × 510 × 550 mm |
| Positioning accuracy | ±0.1 mm |
| Repeatability | **±0.02 mm** |
| Layer resolution | 50–400 µm |
| Max print speed | 200 mm/s |
| Hotend temperature | Up to 300°C |
| Bed temperature | Up to 120°C |
| Motion system | CoreXY + GT2 belts |
| Controller | BigTreeTech + TMC2209 |
| Firmware | Marlin 2.0 |
| Connectivity | WiFi (802.11 b/g/n), Ethernet, USB-C |
| Weight | ~60 kg |

### Tech Stack

`Marlin 2.0` · `CoreXY` · `TMC2209` · `BigTreeTech` · `BLTouch` · `SolidWorks (frame design)`
