### Overview

The **Cybernetics SD15-N** is a proudly Bangladesh-made tactical surveillance drone
engineered for advanced aerial monitoring and reconnaissance. I designed and
implemented the autonomous target-tracking pipeline integrating a computer-vision
inference stack with closed-loop flight control via MAVLink.

### Target Tracking Pipeline

```
Camera (5MP)
     │
     ▼
YOLOv11n inference  (Raspberry Pi 5, 16 GB)
     │ bounding box + centroid offset
     ▼
Error → velocity command  (OpenCV + Python)
     │ via dronekit / pymavlink
     ▼
Pixhawk 2.4.8  (TELEM1 ← RPi GPIO 14/15 UART)
     │
     ▼
Flight actuators  (ArduPilot)
```

### Key Components

| Component | Details |
|---|---|
| Flight computer | Raspberry Pi 5 (16 GB) |
| Flight controller | Pixhawk 2.4.8 |
| GPS | Dual SE 100 |
| Camera | 5 MP (tracking prototype) |
| Vision stack | YOLOv11n + OpenCV |
| MAVLink interface | dronekit, mavproxy, pymavlink |
| Connection | RPi GPIO 14/15 ↔ Pixhawk TELEM1 |
