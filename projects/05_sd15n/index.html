Vision-Guided Target-Tracking Surveillance Drone (YOLOv11n on Raspberry Pi 5 + Pixhawk)

ML-based real-time target tracking on a surveillance hexacopter. YOLOv11n on Raspberry Pi 5, Pixhawk 2.4.8, MAVLink. 1000 ft, 15 km range, three payload variants.

Overview

The Cybernetics SD15-N is a proudly Bangladesh-made tactical surveillance drone engineered for advanced aerial monitoring and reconnaissance. I designed and implemented the autonomous target-tracking pipeline integrating a computer-vision inference stack with closed-loop flight control via MAVLink.

Target Tracking Pipeline

Camera (5MP)
     │
     ▼
YOLOv11n inference  (Raspberry Pi 5, 16 GB)
     │ bounding box + centroid offset
     ▼
Error → velocity command  (OpenCV + Python)
     │ via dronekit / pymavlink
     ▼
Pixhawk 2.4.8  (TELEM1 ← RPi GPIO 14/15 UART)
     │
     ▼
Flight actuators  (ArduPilot)

Key Components

Component Details
